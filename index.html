02 // ABOUT THE ARTIST

凝結時間的呼吸，
讓照片替無法言說的瞬間發聲。

Ansel Lin（林境）是一位長駐台北與東京的獨立攝影師與視覺敘事者。創作跨越人像肖像、建築幾何、城市街頭與人文紀實，曾為多家國際獨立刊物拍攝封面特輯與藝術專題。

在數位影像氾濫的時代，他堅持回歸光影本質。偏好利用晨昏微光與自然漫射光源，以簡練留白的構圖與黑白暗調層次，探討個體在空間中的孤獨與存在感。

01 / LIGHT

自然光線

順應天光脈動，以純粹陰翳雕塑人物情緒與形體輪廓。

02 / SILENCE

空間留白

適度抽離多餘色彩與干擾，讓畫面的沉默成為最深沉的力量。

03 / STORY

編輯敘事

以雜誌篇章架構組織畫面，每張照片皆是長篇故事的引言。

04 // EDITORIAL SERIES

攝影專案 Projects

深入探索四組具備完整敘事結構的主題攝影企劃。每項專案皆有特定拍攝命題、創作初衷與獨家圖輯。

METHODOLOGY

創作流程與典藏工藝

PHASE 01

靈感對話 Dialogue

深入溝通拍攝對象的氣質特點、企劃情緒板（Moodboard）與影像調性定位。

PHASE 02

場勘與光影 Scouting

預測自然光線移動軌跡、空間架構與色彩搭配，建立拍攝日精準的時間表。

PHASE 03

沈浸拍攝 The Session

營造放鬆且具默契的快門節奏，專注於不刻意擺拍下的真實神情與呼吸感。

PHASE 04

編輯與微噴 Archival

嚴選色溫灰階調色，並提供符合博物館級無酸純棉藝術紙之微噴典藏輸出。
